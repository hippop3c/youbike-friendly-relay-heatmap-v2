# 雙北友愛接力逐日熱力圖 V6

線上儀表板：<https://hippop3c.github.io/youbike-friendly-relay-heatmap-v2/>

## 功能

- 沿用月份、平假日、縣市、行政區、指標、平日日均用量、場站搜尋等篩選；時間粒度可切換每小時或每半小時，預設為每小時。
- 新增日期複選與逐日場站明細；複選日期以選取日期數計算算術平均，沒有紀錄的站時以 0 納入。
- 調度行為拆分為「調出、綁車、調入、解綁車」，不合併計算。
- 新增雙北 ABC 級場站篩選與目前明細 CSV 匯出。
- 調度動作圓點出現橘色或綠色外圈時，代表該站在選定日與時段亦發生對應的滿借或空還；場站彈窗可查看同站覆蓋站時。
- 地圖上方固定顯示調出、綁車、調入、解車四項單獨覆蓋率，以及「調出＋綁車」「調入＋解車」兩項聯集覆蓋率；聯集同站同時段只算一站。
- 地圖與逐日明細可拖曳分隔線左右調整寬度。
- 右側新增「卡號追蹤」，可輸入外觀卡號後五碼查看目前月份與所選日期的每日滿借、空還及合計次數。
- 卡號資料只發布正規化後五碼、每日合計及同尾碼完整卡數；不發布完整卡號、帳號、訂單號、場站或時間戳。後五碼不具唯一性，重複時畫面會明確標示為多卡合計。

## 資料範圍

- 2026-07-01～2026-07-31：友愛接力依既有口徑排除 7/10、7/11，共 29 日。
- 2026-08-01～2026-08-31：31 日。
- 2026-09-01～2026-09-30：30 日。

## 計算口徑

- 滿借、空還：行動電話會員唯一訂單，按場站 × 日期 × 30 分鐘計次。
- 調出、綁車、調入、解綁車：按場站 × 日期 × 30 分鐘 × 動作，各自採單筆任務車輛數最大值，以延續原熱力圖口徑。
- 日期複選：各站時數值總和 ÷ 有效選取日期數；未發生值為 0。
- 每小時模式會先合併同一日期、同一場站的兩個半小時資料，再以站級布林判斷是否發生事件或調度；跨半小時發生的事件與調度仍視為同小時覆蓋。
- 覆蓋率分母只計事件站集合，分子只計事件站集合與對應調度站集合的交集：調出／綁車對應滿借，調入／解車對應空還。
- 「調出＋綁車」及「調入＋解車」採調度站集合聯集後再與事件站集合取交集；同站、同日、同時段重複動作只算一站。
- 多日複選為交集站時總數 ÷ 事件站時總數，所以分子不會大於分母，覆蓋率不會超過 100%。
- 平假日會與勾選日期取交集後再計算。
- ABC 級門檻（日均用量）：台北 A ≥ 200、B 100–199、C < 100；新北 A ≥ 100、B 50–99、C < 50。
- 見車率、見位率沿用月別平假日平均，作為參考指標，不宣稱為逐日值。
- 卡號每日滿借按借車日期、每日空還按還車日期計算；沿用行動電話會員與唯一訂單口徑。

逐日建置程式位於 `scripts/build_daily_v2.py`，產出稽核摘要為 `build-summary.json`；卡號每日建置程式位於 `scripts/build_card_daily_v1.py`，稽核摘要為 `card-build-summary.json`；回歸檢查位於 `scripts/verify_hourly_coverage_v4.mjs` 與 `scripts/verify_card_daily_v1.mjs`。
